# Microsoft Store 掲載テキスト

## 製品名

PCChecker

## 短い説明

Windows PC のスペックを自動で診断し、買い替えやアップグレードの判断に役立つ無料ツールです。

## 詳細説明

PCChecker は、お使いの Windows PC のスペックをローカルで分析し、用途に合わせた評価とアップグレード候補を表示する無料アプリです。

CPU、メモリ、GPU、ストレージなどの構成から、「まだ使えるのか」「どこを強化すべきか」「買い替えた方がよいのか」を判断できます。ロースペック・ミドルスペック・ハイスペックの 3 つの基準を切り替えながら、総合スコア・部品別評価・買い替え判定を確認できます。専門用語に詳しくない方にも読み取りやすい表示にしています。

診断はすべてお使いの PC 内で行われ、氏名や PC 名などの個人情報を外部へ送信することはありません。アップグレード候補の価格表示に楽天市場の参考情報を利用する場合があります。

特徴:

- PC の状態をわかりやすく表示
- すべての機能を無料で利用
- 総合スコア・部品別評価・買い替え判定を表示
- スペックを買い替えやアップグレードの判断材料へ整理
- 診断はすべてお使いの PC 内で処理
- 楽天市場の参考価格で候補パーツや買い替え先を確認

## 主な機能

- CPU、メモリ、GPU、ストレージ、OS、ディスプレイ、ネットワーク、マザーボードの自動診断
- 0 から 100 点の総合スコア表示
- ロースペック、ミドルスペック、ハイスペックの評価基準切り替え
- 部品別の評価とアップグレード提案
- 買い替えとアップグレードの判定
- AI アクセラレータの検出と TOPS 目安表示
- ストレージの状態、TRIM 設定、電源プランなどのシステム健全性チェック
- 推定消費電力と推奨電源容量の表示
- 楽天市場の参考価格と商品リンクの表示
- アプリ内からのフィードバック送信

## 審査メモ用の補足文

PCChecker は、Windows PC のローカル環境で PC スペックを診断し、結果を既定ブラウザに表示するデスクトップアプリです。起動時にローカル Web サーバを `127.0.0.1` で起動し、診断 UI を既定ブラウザで開きます。

フルトラスト権限は、WMI やローカルシステム情報を利用して CPU、GPU、メモリ、ストレージなどの PC 構成を取得し、ローカルで診断するために必要です。診断はすべてお使いの PC 内で行われ、氏名や PC 名などの個人情報を外部へ送信することはありません。

価格表示には楽天市場の商品情報または中継キャッシュを利用する場合があります。楽天 API の認証情報を含む `.env` は秘密鍵を含むため配布物には同梱していません。`.env` が無い環境でも、価格取得は中継キャッシュまたはアプリ内のフォールバック表示により動作を継続します。

アプリ内フィードバックは利用者が任意で送信した場合のみ外部送信されます。送信時には入力内容に加えてアプリバージョン、OS/実行環境情報、送信時刻が付与される場合があります。診断結果の添付は利用者がチェックした場合のみ行われ、氏名や PC 名などの個人情報は含めない設計です。
