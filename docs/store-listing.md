# Microsoft Store 掲載テキスト

## 製品名

PCカスタムサポート

## 短い説明

お使いのパソコンの性能をわかりやすく解説し、パーツ交換やパソコンの買い替えをアドバイスする無料アプリです。

## 詳細説明

PCカスタムサポートは、お使いの Windows パソコンの CPU、メモリ、GPU、ストレージなどを確認し、現在の性能をわかりやすく解説する無料アプリです。

用途に合わせてロースペック、ミドルスペック、ハイスペックの基準を切り替えながら、総合スコア、パーツ別評価、パーツ交換の優先度、パソコンの買い替えを検討する目安を確認できます。

「今の PC がまだ使えるか」「メモリやストレージを増やすべきか」「買い替えを考える段階か」を知りたい方に向いています。

アプリ内のリンクから、楽天市場に掲載されている関連商品のページを確認できる場合があります。

特徴:

- お使いのパソコンの性能をわかりやすく解説
- CPU、メモリ、GPU、ストレージなどを確認
- 用途別の基準で総合スコアを表示
- パーツ別の評価を表示
- パーツ交換の優先度を表示
- パソコンの買い替えを検討する目安を表示
- 関連商品のページを確認できる場合あり

## 主な機能

- CPU、メモリ、GPU、ストレージ、OS、ディスプレイ、ネットワーク、マザーボードの自動確認
- 0 から 100 点の総合スコア表示
- ロースペック、ミドルスペック、ハイスペックの評価基準切り替え
- パーツ別の評価とパーツ交換の提案
- パソコンの買い替えを検討する目安の表示
- AI アクセラレータの検出と TOPS 目安表示
- ストレージの状態、TRIM 設定、電源プランなどのシステム健全性チェック
- 推定消費電力と推奨電源容量の表示
- パーツやパソコンの商品ページを開く機能
- アプリ内からのフィードバック送信

## 推奨年齢区分の補足

全年齢向けを想定しています。暴力、性的表現、ギャンブル、ユーザー生成コンテンツ、位置情報共有などの年齢制限が必要な要素はありません。

## 審査メモ用の補足文

PCカスタムサポート は、Windows PC のローカル環境で PC スペックを診断し、結果を既定ブラウザに表示するデスクトップアプリです。起動時にローカル Web サーバを `127.0.0.1` で起動し、診断 UI を既定ブラウザで開きます。

フルトラスト権限は、WMI やローカルシステム情報を利用して CPU、GPU、メモリ、ストレージなどの PC 構成を取得し、ローカルで診断するために必要です。診断はすべてお使いの PC 内で行われ、氏名や PC 名などの個人情報を外部へ送信することはありません。

価格表示には楽天市場の商品情報または中継キャッシュを利用する場合があります。楽天 API の認証情報を含む `.env` は秘密鍵を含むため配布物には同梱していません。`.env` が無い環境でも、価格取得は中継キャッシュまたはアプリ内のフォールバック表示により動作を継続します。

アプリ内フィードバックは利用者が任意で送信した場合のみ外部送信されます。送信時には入力内容に加えてアプリバージョン、OS/実行環境情報、送信時刻が付与される場合があります。診断結果の添付は利用者がチェックした場合のみ行われ、氏名や PC 名などの個人情報は含めない設計です。
