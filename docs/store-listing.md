# Microsoft Store 掲載テキスト

## 製品名

PCChecker

## 短い説明

Windows PC のスペックを自動診断し、買い替えやアップグレードの判断を支援する無料ツールです。

## 詳細説明

PCChecker は、お使いの Windows PC のスペックをローカルで分析し、用途に合わせた評価とアップグレード候補を表示する無料アプリです。

CPU、メモリ、GPU、ストレージなどの構成を確認し、「まだ使えるのか」「どこを強化すべきか」「買い替えた方がよいのか」を把握できます。専門用語に慣れていない方でも見やすいよう、ロースペック、ミドルスペック、ハイスペックの基準を切り替えながら、総合スコア、部品別評価、買い替え判定を確認できます。

PC の構成情報は利用者の PC 上で処理され、既定では外部に送信されません。アップグレード候補の価格表示には楽天市場の参考情報を利用する場合がありますが、個人情報は送信しません。

特徴:

- PC の状態をわかりやすく表示
- 無料で利用可能
- スコア、部品別評価、買い替え判定を確認
- スペック情報を、買い替えやアップグレードの判断材料として整理
- PC スペック診断はローカル処理で安心
- 楽天市場の参考価格をもとに、候補パーツや買い替え候補を確認可能

## 主な機能

- CPU、メモリ、GPU、ストレージ、OS、ディスプレイ、ネットワーク、マザーボードの自動診断
- 0 から 100 点の総合スコア表示
- ロースペック、ミドルスペック、ハイスペックの評価基準切り替え
- 部品別の評価とアップグレード提案
- 買い替えとアップグレードの判定
- AI アクセラレータの検出と TOPS 目安表示
- ストレージ健全性、TRIM 設定、電源プランなどのシステム健全性チェック
- 推定消費電力と推奨電源容量の表示
- 楽天市場の参考価格、商品リンク表示
- アプリ内フィードバック送信

## 審査メモ用の補足文

PCChecker は、Windows PC のローカル環境で PC スペックを診断し、結果を既定ブラウザに表示するデスクトップアプリです。起動時にローカル Web サーバを `127.0.0.1` で起動し、診断 UI を既定ブラウザで開きます。

フルトラスト権限は、WMI やローカルシステム情報を利用して CPU、GPU、メモリ、ストレージなどの PC 構成を取得し、ローカルで診断するために必要です。PC の診断情報は既定では外部に送信されません。

価格表示には楽天市場の商品情報または中継キャッシュを利用する場合があります。楽天 API の認証情報を含む `.env` は秘密鍵を含むため配布物には同梱していません。`.env` が無い環境でも、価格取得は中継キャッシュまたはアプリ内のフォールバック表示により動作を継続します。

アプリ内フィードバックは利用者が任意で送信した場合のみ外部送信されます。送信時には入力内容に加えてアプリバージョン、OS/実行環境情報、送信時刻が付与される場合があります。診断結果の添付は利用者がチェックした場合のみ行われ、氏名や PC 名などの個人情報は含めない設計です。
